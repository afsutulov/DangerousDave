# Dangerous Dave in the Haunted Mansion — Go Edition v1.0.0

An unofficial native recreation of Dangerous Dave II, written in Go for Windows, Linux, and macOS.

Explore all eight original levels with classic EGA artwork, eight-direction shotgun combat, automatic reloading, treasure-filled closets, teleport doors, monsters, and both boss encounters. Includes illustrated death sequences, save/load, fullscreen support, and a new application icon.

The project runs without MS-DOS or an emulator. Game data is embedded in the executable, and the included build helper supports x64 and ARM64 builds with Windows EXE icons and macOS application bundles.

This source release includes the Go project, required assets, English and Russian build instructions, gameplay screenshots, and license notices. Gameplay and sound are reconstructed and differ from the original DOS release.
